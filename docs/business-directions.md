# Выбранные направления развития (октябрь 2026)

Рынок: Кыргызстан. Работаем только по двум категориям ниже.

## 1. HoReCa-tech (рядом с QR-меню)
1. Программа лояльности и CRM через QR — баллы за номер телефона, база гостей, рассылки в WhatsApp.
2. Оплата и разделение счёта по QR за столом — Элкарт, MBank, O!Деньги, Optima.
3. Анализ отзывов — сбор из 2GIS / Google / Instagram, ИИ-сводка проблем, шаблоны ответов.
4. Фудкост и учёт склада для небольших кафе (кыргызский + русский), дешевле и проще iiko / R-Keeper.
5. Dark kitchen / фуд-холл — несколько брендов доставки на одной кухне, аренда мест.

## 2. ИИ и цифровые сервисы
6. ИИ-ассистент для WhatsApp-бизнеса (кыргызский + русский): ответы клиентам, запись, приём заказов.
7. Онлайн-запись для салонов, клиник, автомоек (аналог YCLIENTS) с оплатой через местные кошельки.
8. Аутсорс-бухгалтерия для ИП и малого бизнеса с автоматизацией (ГНС, ЭСФ, ККМ) по подписке.
9. ИИ-озвучка и субтитры на кыргызском для YouTube, курсов, рекламы.
10. Обучение бизнеса работе с ИИ — короткие практические курсы.

## Приоритет
Начинать с модулей, которые продаются текущим клиентам QR-меню как допродажа: **1, 2, 3, 6**.
